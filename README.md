# MTProto_Checker
MTProto proxies verification program for Telegram.

Программа проверки MTProto proxy для Telegram.
Чтобы постоянно не искать рабочие прокси для телеги - экспортируем историю чатов с публичных каналов публикующих MTProto, например:
https://t.me/TProxyRU
https://t.me/ProxyMTProto
https://t.me/ProxyFreeMTProto
https://t.me/ProxyFree_Ru

Программа использует официальную библиотеку Telegram - TDLib (Telegram Database Library) версии 1.8.67.

  **************************************************
  Вы ДОЛЖНЫ получить свой собственный api_id и api_hash по адресу https://my.telegram.org
  You MUST obtain your own api_id and api_hash at https://my.telegram.org
  **************************************************
  
https://my.telegram.org в России заблокирован. Сайт не даст доступ через ВПН, если страна зарегистрированного телефонного номера не соответствует IP.
Чтобы получить доступ, необходимо в файл hosts добавить строчку: 149.154.167.220 my.telegram.org
По умолчанию файл находится по пути: "C:\Windows\System32\drivers\etc\".

Заходим на сайт, переходим на страницу -> "API development tools", вводим номер телефона и подтверждаем вход кодом из Telegram.

Заполняем описание и получаем API_ID, API_HASH и ID датацентра DC.

!!!!!!!!!Никому не передавать код доступа, API_ID, API_HASH!!!!!!!!!

При первом запуске программы необходимо скопировать и вставить в соответствующие поля API_ID и API_HASH и подтвердить ввод клавишей Enter.

Если DC не равен 2 - меняем в программе DC_ID на свой.
